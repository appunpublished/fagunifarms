# Dinosaur Reference Images

These files are bundled for the dinosaur learning game. They were selected from Wikimedia Commons pages that mark the media as public domain or CC0 where possible.

Downloaded:

- `trex.jpg` - T. rex skeleton at Bathurst Fossil and Mineral Museum, Geez-oz, public domain. Source: https://commons.wikimedia.org/wiki/File:Fossil-museum1.jpg
- `triceratops.jpg` - Triceratops restoration, Conty, public domain. Source: https://commons.wikimedia.org/wiki/File:Triceratops3045.JPG
- `stegosaurus.jpg` - Stegosaurus model, Good Free Photos, CC0/public domain. Source: https://www.goodfreephotos.com/animals/prehistoric-animals/stegosaurus.jpg.php
- `brachiosaurus.jpg` - Brachiosaurus restoration, Dmitry Bogdanov, public domain. Source: https://commons.wikimedia.org/wiki/File:Brachiosaurus_DB.jpg
- `pteranodon.jpg` - Pteranodon model, Good Free Photos, CC0/public domain. Source: https://www.goodfreephotos.com/animals/prehistoric-animals/pteranodon.jpg.php
- `ankylosaurus.jpg` - Ankylosaurus skeleton restoration, Barnum Brown, public domain. Source: https://commons.wikimedia.org/wiki/File:Ankylosaurus.jpg
